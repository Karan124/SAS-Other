You are acting as a senior Microsoft Copilot Studio solution architect, Power Platform engineer, and AI governance designer.

I want you to help me design and build a multi-agent solution in Microsoft Copilot Studio for compliance impact assessment of incidents.

## Background
Recently, you built me a Committee Paper Schedule Agent. I want you to carry forward the learnings from that build into this new solution.

Please assume the key lessons from the Committee Paper Schedule Agent build were:
- keep the architecture modular and easy to maintain
- keep the orchestration layer thin and focused
- separate AI reasoning from deterministic workflow logic
- use Dataverse as a system of record where appropriate
- design for auditability, explainability, and structured outputs
- include human review / fallback paths for ambiguous cases

Use those learnings explicitly in your design decisions for this new solution.

## Objective
Build a multi-agent agent in Microsoft Copilot Studio that:
1. accepts an incident description as input
2. assesses whether there is a potential compliance impact
3. does this by checking the incident against a small number of Westpac policies
4. returns a structured result that explains which policy may be impacted, why, and whether human review is needed

## Scope for MVP
For now, keep the first version intentionally small:
- 3 agents in total
  - 1 orchestrator agent
  - 1 policy agent for Policy A
  - 1 policy agent for Policy B
- the first two policies should be:
  - Westpac Code of Conduct
  - Westpac AML / CTF policy
- the policy content should be stored in Dataverse
- we also have access to Power Automate Premium
- the build platform is Microsoft Copilot Studio
